# Checklist

## 用户系统与认证
- [ ] 手机号 + 短信验证码注册/登录接口可用，返回 JWT token
- [ ] 微信 OAuth 扫码登录在网页端与小程序端均可用
- [ ] 用户可编辑个人资料（昵称、头像、简介、兴趣标签、设备信息）
- [ ] 隐私设置（资料/动态可见性）生效
- [ ] 第三方登录抽象层已预留（Google/Apple 接口占位）
- [ ] 所有受保护接口启用 JWT 认证与权限校验

## 论坛核心
- [ ] 5 个默认板块已通过种子数据初始化（观测分享/设备讨论/活动招募/天文知识/求助）
- [ ] 用户可发帖（文字 + 多图，普通图片单张 ≤10MB，支持 FITS 等专业格式上传）
- [ ] 回帖、评论、点赞功能可用
- [ ] 帖子支持分类、标签、搜索、分页
- [ ] 用户申请新板块可由管理员审核上线
- [ ] 发帖后按规则发放积分

## 专业天文图像处理
- [ ] 支持 FITS、TIFF、RAW（CR2/NEF/ARW）等专业格式上传
- [ ] FITS 大小限制 ≤100MB，TIFF/RAW ≤50MB，普通图片 ≤10MB
- [ ] FITS 文件由后端生成 PNG/JPEG 预览图用于网页/小程序展示
- [ ] 浏览器直接展示预览图，不加载原始 FITS 文件
- [ ] 解析并保留 FITS header 元数据（观测目标/设备/曝光时间/滤镜/赤经赤纬坐标）
- [ ] 帖子详情展示 FITS 元数据
- [ ] 画廊详情展示 FITS 元数据
- [ ] 提供专业格式原始文件下载链接
- [ ] 专业格式上传给予差异化积分奖励（高于普通图片）

## Follow 与社交基础
- [ ] Follow/Unfollow 功能可用，关系双向同步
- [ ] 个人主页展示 Follow 列表与动态
- [ ] 关注动态流（时间线）按时间倒序展示

## 积分系统
- [ ] 积分赚取规则引擎覆盖：发帖、上传照片、获赞、画廊通过、活动参与
- [ ] 积分余额查询 + 赚取/消费明细记录可查
- [ ] 积分兑换（虚拟徽章/头像框/论坛特权）可用，折扣卡占位
- [ ] 积分不足时兑换被拒绝并提示
- [ ] 管理员可查看积分交易流水并调整

## 荣耀画廊
- [ ] 用户可从已发布照片申请进入画廊（status=pending）
- [ ] 管理员可审核画廊申请（通过/拒绝）
- [ ] 审核通过后照片进入画廊公开展示
- [ ] 审核通过后自动发放大量积分
- [ ] 画廊支持分类浏览、按时间/点赞排序、搜索
- [ ] 画廊详情展示 FITS 元数据 + 原始文件下载链接

## 活动系统
- [ ] 用户可创建活动（线上/线下 + 报名上限）并提交审核
- [ ] 管理员可审核活动
- [ ] 审核通过的活动可被用户报名，满员时拒绝
- [ ] 官方可发布定期活动
- [ ] "我的活动"已报名列表可用

## 微信小程序
- [ ] 小程序基础框架 + 微信登录可用
- [ ] 小程序可浏览帖子、发帖（文字+图片）
- [ ] 小程序 Follow 功能可用
- [ ] 小程序可查看积分、画廊、活动列表
- [ ] 小程序发帖通过后端 API 同步到网页论坛（写入主库即可见）

## 后台管理系统
- [ ] 管理员登录与权限控制（角色区分）可用
- [ ] 内容审核（帖子/画廊/活动/板块申请）可用
- [ ] 用户管理（列表/封禁/积分调整/角色）可用
- [ ] 积分与交易管理可用
- [ ] 数据统计看板展示用户/帖子/画廊/活动数据
- [ ] 论坛板块管理（启用/禁用/排序）可用
- [ ] 管理操作写入 admin_logs

## 网页论坛前端设计
- [ ] 采用太空科技感视觉（深空配色 + 星点/星云点缀 + 霓虹蓝/青/紫高光）
- [ ] 使用实体不透明深色卡片 + 发光边框（不使用半透明玻璃拟态，保证文字可读性）
- [ ] 科技感无衬线字体，中英文/数字混排可读
- [ ] 关键页面克制微动效（星空粒子/流星/滚动渐入/悬停反馈），不干扰阅读与首屏性能
- [ ] 响应式布局，桌面/移动/微信内置浏览器自适应
- [ ] 核心入口（发帖/搜索/个人中心/积分中心）一键可达
- [ ] 加载状态使用骨架屏，关键操作有即时反馈，错误提示友好
- [ ] 图片画廊式预览，FITS 预览图流畅切换
- [ ] 暗色主题为主，荣耀画廊突出天文美感与大图沉浸展示
- [ ] 视觉层次清晰、信息密度合理、键盘可访问
- [ ] 动效异步加载，首屏内容优先，不被动效拖慢

## 非功能与部署
- [ ] 普通图片上传支持常见格式，单张 ≤10MB，存储至对象存储并返回 CDN URL（专业天文格式见"专业天文图像处理"）

- [ ] 数据库迁移脚本 + 种子数据可重复执行
- [ ] Docker 化部署脚本 + Nginx 配置就绪
- [ ] 国内云 ECS + SLB + CDN + HTTPS + 域名配置完成
- [ ] WAF、DDoS 防护、基础监控与日志、数据库备份就绪
- [ ] 论坛列表页响应时间 < 2s，图片加载使用 CDN
- [ ] 兼容国内主流浏览器及微信内置浏览器
- [ ] Swagger/OpenAPI 接口文档生成
- [ ] 用户操作手册 + 管理员使用文档完成
